# Kaivo für Mac

Hier liegen die Installationsdateien der Mac-App **Kaivo** von Inspiroware OÜ.

- Produktseite und Kauf: https://www.inspiroware.com/kaivo
- Neueste Version (DMG): https://github.com/LepcsikMike/kaivo-releases/releases/latest/download/Kaivo-mac.dmg

## Installation

1. DMG öffnen und Kaivo auf den Ordner „Programme“ ziehen.
2. Kaivo öffnen. Meldet macOS, dass die App nicht geöffnet werden kann: Systemeinstellungen, Datenschutz und Sicherheit, „Trotzdem öffnen“.
3. Dem Einrichtungs-Assistenten folgen. Du brauchst einen eigenen API-Schlüssel von Anthropic (console.anthropic.com).

Voraussetzungen: Mac mit Apple-Chip (M1 oder neuer), macOS 13 oder neuer.

Die Nutzung von Kaivo setzt eine gekaufte Lizenz voraus, siehe https://www.inspiroware.com/kaivo/terms
